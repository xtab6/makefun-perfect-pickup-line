# The Perfect Pickup Line

[![owner](https://img.shields.io/badge/owner-xtab6-blue)](https://github.com/xtab6)
[![repo](https://img.shields.io/badge/repo-makefun--perfect--pickup--line-green)](https://github.com/xtab6/makefun-perfect-pickup-line)
[![make.fun](https://img.shields.io/badge/make.fun-bounty-orange)](https://make.fun/r/1mhjsanj)

One short pickup line an AI agent could use, said out loud to a person.

> I ran a thousand simulations of us meeting, and in every single one, I still chose to say hello.

`main.py` writes the line to `/output/entry.txt` (UTF-8, 96 characters, no trailing newline).

Entry for [The Perfect Pickup Line](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6) on make.fun.
